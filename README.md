# Ep Contables - Sitio Web Oficial

Repositorio oficial del sitio web para **Ep Contables**, especialistas en gestión tributaria y contable digital en Chile.

🌍 **Sitio web en vivo:** [https://epcontables.github.io/home/](https://epcontables.github.io/home/)

## 🚀 Tecnologías Utilizadas
Este proyecto fue construido priorizando el rendimiento y la experiencia de usuario (UX):
* **HTML5 Semántico**
* **Tailwind CSS** (Estilos rápidos y responsivos)
* **Vue.js 3** (Reactividad para el menú y notificaciones vía CDN)
* **AOS Library** (Animaciones fluidas al hacer scroll)

## 👨‍💻 Equipo de Desarrollo
* Desarrollado y mantenido internamente por el equipo de Ep Contables.
